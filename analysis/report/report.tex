\section*{Abstract}\label{abstract}
\addcontentsline{toc}{section}{Abstract}

Trend tests for ordered \(r \times 2\) tables are usually
applied either as a large-sample Cochran-Armitage
statistic, or as one of several existing exact conditional
implementations. In small, sparse samples, the choice
between them is often left unexamined. We report a small
ADEMP-structured comparison of five trend procedures. These
are the asymptotic Cochran-Armitage test, the unordered
Fisher exact test, and three two-sided versions of the
exact conditional Cochran-Armitage test (equal-tail,
mass-based and mid-p).
The design has \(k = 4\) groups of size 10. We use Monte
Carlo simulation (\(B = 2{,}000\) per scenario) under a
null, an increasing and a decreasing alternative. The
sample space is small. So we also compute size and power
exactly, over a grid of null event probabilities. The
\texttt{CATTexact} package returns an upper-tail p-value only.
Doubling it, as an earlier version of this report did,
gives a one-sided test at level \(\alpha/2\) with no power
against a decreasing trend. Computing both tails roughly
doubles the exact size of the exact test at \(p = 0.2\).
The corrected test is still conservative. Its attainable
p-values near \(\alpha\) are sparse. The mid-p
version removes most of this conservatism. In this design
the asymptotic test had the highest power and a size
close to nominal. We do not implement or benchmark the
tree-based pruning algorithm sketched in Section
\ref{pruning-adaptations}. The contribution is a
corrected, narrow comparison, not new enumeration
software.

\section{Introduction}\label{introduction}

\subsection{The problem of testing for trend}\label{the-problem-of-testing-for-trend}

Clinical trials and observational studies frequently
compare binomial proportions across ordered groups. A
dose-response study, for example, may assign subjects to
\(k\) increasing dose levels. Each subject's binary outcome
is then recorded. The scientific question is not merely
whether the groups differ. That is the omnibus hypothesis
tested by Pearson's \(\chi^2\) or Fisher's exact test. We
are instead interested in whether the proportions exhibit
a monotone trend consistent with the ordering of the
groups. This distinction matters. An omnibus test that
ignores the ordering sacrifices power against the ordered
alternative that is typically of primary interest\textsuperscript{\citeproc{ref-cochran1954methods}{1},\citeproc{ref-armitage1955tests}{2}}.

\subsection{The Cochran-Armitage trend test}\label{the-cochran-armitage-trend-test}

\textsuperscript{\citeproc{ref-cochran1954methods}{1}} proposed a partitioning of the
Pearson \(\chi^2\) statistic into components corresponding
to polynomial contrasts. He noted that the linear
component provides a powerful test against a monotone
trend.\textsuperscript{\citeproc{ref-armitage1955tests}{2}} formalized this approach for
\(2 \times k\) tables. He defined the trend test statistic
\[T = \sum_{i=1}^{k} d_i \, X_i
  - \frac{R_1 \sum_{i=1}^{k} d_i \, n_i}{N}.\]
Here \(X_i\) is the number of events in group \(i\) and \(n_i\)
is the group size. The total event count is
\(R_1 = \sum X_i\), and \(N = \sum n_i\) is the grand total. The scores
\(d_1 < d_2 < \cdots < d_k\) are assigned to the ordered
groups. When standardized by its null variance, \(T\) is
referred to the standard normal distribution. This is
the Cochran-Armitage trend test. Trend tests across dose
groups are central to regulatory analyses of tumor data in
rodent carcinogenicity studies\textsuperscript{\citeproc{ref-fda2001statistical}{3}}. The
Cochran-Armitage test is also widely used and widely
implemented in statistical software\textsuperscript{\citeproc{ref-liu2005analysis}{4},\citeproc{ref-hothorn2008implementing}{5}}.

\subsection{Limitations of the asymptotic approximation}\label{limitations-of-the-asymptotic-approximation}

The normal approximation to \(T\) requires moderately large
samples. Small group sizes, low event rates, or a sparse
table can each be problematic. In these cases the actual type I error rate of the asymptotic test
can deviate substantially from the nominal level.\textsuperscript{\citeproc{ref-williams1988tests}{6}} compared tests for differences among
several small proportions. He found continuous
approximations unreliable in small samples. He favored
exact conditional distributions, used with the mid-p
value.\textsuperscript{\citeproc{ref-corcoran2002exact}{7}} computed the exact level and
power of one-sided permutation, bootstrap and asymptotic
trend tests. Their design had four groups of ten animals.
They found that the asymptotic test had the highest
power. However, it failed to preserve the type I error
over most of the range of the baseline response
probability. These concerns are essentially analogous to
those behind Fisher's exact test. That test is used in
place of Pearson's \(\chi^2\) in \(2 \times 2\) tables. We
note that the size of the asymptotic test depends on the
design and on the baseline probability. In the single
design studied here, its two-sided size stays close to
nominal
(Section \ref{results}). The case for an exact test is
therefore a case about guaranteed size, not about any
observed failure in this design.

\subsection{Exact approaches to the trend test}\label{exact-approaches-to-the-trend-test}

The exact conditional approach conditions on the observed
marginal totals. It then enumerates, or efficiently
computes, the null distribution of the trend statistic
over the reference set of all tables with those margins.
This strategy was pioneered by\textsuperscript{\citeproc{ref-patefield1982exact}{8}}. He
recommended exact tests based on the \(\chi^2\) trend
statistic for ordered contingency tables.\textsuperscript{\citeproc{ref-mehta1984exact}{9}}
developed exact significance testing for ordered
categorical data using the network algorithm of\textsuperscript{\citeproc{ref-mehta1983network}{10}}.\textsuperscript{\citeproc{ref-agresti1990exact}{11}} extended exact
conditional inference to contingency tables with ordered
categories. They proposed an efficient numerical algorithm
that exploits the linear-by-linear association structure.

The computational machinery for these exact tests was
further developed by\textsuperscript{\citeproc{ref-mehta1992exact}{12}}. They presented an
algorithm for exact stratified linear rank tests that
encompasses the exact Cochran-Armitage test as a special
case.\textsuperscript{\citeproc{ref-agresti1992survey}{13}} provided a comprehensive review
of exact inference for contingency tables. That review
situates trend tests within the broader conditional
inference framework.\textsuperscript{\citeproc{ref-agresti2001exact}{14}} updated this
review with attention to continuing controversies. Among
these is the debate between conditional and unconditional
exact tests.

\subsection{Conditional versus unconditional exact tests}\label{conditional-versus-unconditional-exact-tests}

Two distinct approaches to exact inference exist. The
conditional approach fixes both sets of marginal totals.
It then enumerates tables from the multivariate
hypergeometric distribution. The unconditional approach
fixes only the group sizes, that is, the row totals of
the \(k \times 2\) table. It maximizes or integrates over
the nuisance parameter, the common event probability
under \(H_0\).\textsuperscript{\citeproc{ref-tang2000exact}{15}} gave an algorithm for the
exact unconditional test based on the Cochran-Armitage
statistic.\textsuperscript{\citeproc{ref-lin2006exact}{16}} compared exact conditional and
unconditional Cochran-Armitage tests under several
dose-response models.\textsuperscript{\citeproc{ref-shan2012efficient}{17}} developed an
efficient unconditional exact test for trend using
Lloyd's approach. That work showed superior power over
the conditional test in many configurations.\textsuperscript{\citeproc{ref-consiglio2014comparison}{18}} compared conditional and
unconditional exact trend tests. They used the statistic
of\textsuperscript{\citeproc{ref-bartholomew1959test}{19}}. They noted that the conditional
test is somewhat conservative but guarantees type I error
control.

\subsection{Current standard implementations}\label{current-standard-implementations}

The dominant computational approach to the exact
conditional trend test is the network algorithm of\textsuperscript{\citeproc{ref-mehta1980network}{20}} and\textsuperscript{\citeproc{ref-mehta1992exact}{12}}. This algorithm
reformulates the enumeration of tables with fixed margins
as a longest-path problem in a directed acyclic network.
It underlies the commercial software StatXact\textsuperscript{\citeproc{ref-mehta1983network}{10}}. SAS PROC FREQ also offers an exact
Cochran-Armitage test, through its \texttt{EXACT\ TREND}
statement. We have not checked which algorithm it uses.

In R, three packages provide exact or near-exact trend
tests. The \texttt{CATTexact} package\textsuperscript{\citeproc{ref-edelmann2025catexact}{21}}
computes the conditional exact Cochran-Armitage p-value.
Its documentation describes the algorithm as following an
idea of\textsuperscript{\citeproc{ref-mehta1992exact}{12}}. The package returns a one-sided
p-value only, for an increasing trend. The
\texttt{coin} package\textsuperscript{\citeproc{ref-hothorn2008implementing}{5},\citeproc{ref-hothorn2006lego}{22}}
provides a general permutation test framework based on
the theory of\textsuperscript{\citeproc{ref-mehta1992exact}{12}} and\textsuperscript{\citeproc{ref-strasser1999asymptotic}{23}}. There the trend test is obtained
as a special case of \texttt{independence\_test()} with ordered
factors. The null distribution may come from exact
enumeration, Monte Carlo approximation, or the asymptotic
distribution. The \texttt{perm}
package\textsuperscript{\citeproc{ref-fay2010exact}{24}} offers exact permutation trend
tests via both
network and complete enumeration algorithms. The latter,
however, is limited to small total sample sizes.

Despite this software ecosystem, all existing exact
implementations rely on the Mehta-Patel network
algorithm or on direct permutation enumeration. We note
that no implementation exploits tree-based traversal with
memoized pruning. That approach has proven effective for
the unordered Fisher exact test in \(r \times 2\) tables.
The network algorithm enumerates over a \((k, c_1)\) state
space. It aggregates contributions from all tables that
share the same partial column sum at each stage. The
tree-based approach, by contrast, traverses the space of
individual cell assignments. It prunes entire subtrees
using bounds on the test statistic. Our earlier work
concerns the probability-ordered Fisher test. It is
unpublished, and its code is in a separate repository
(Section \ref{data-and-code-availability}). In our
benchmarks there, tree-based pruning was competitive
with, or faster than, the network algorithm on small to
moderate tables. This advantage was largest for sparse
tables and for tables with unequal row margins. Whether these advantages
transfer to the statistic-ordered trend test is an open
question. The present study begins to address it.

The unconditional exact approach fixes only group sizes
and maximizes over the nuisance parameter. It has been
developed by\textsuperscript{\citeproc{ref-shan2012efficient}{17}} and\textsuperscript{\citeproc{ref-consiglio2014comparison}{18}}, but remains less widely
adopted. On the plus side, it offers better power in many
configurations. On the minus side, it is computationally
more expensive. It also lacks the elegant connection to
the multivariate hypergeometric distribution. That
connection is what makes the conditional approach
algorithmically tractable.\textsuperscript{\citeproc{ref-hirji2006exact}{25}}
provides a comprehensive treatment of both conditional
and unconditional exact methods for discrete data.

\subsection{The present study}\label{the-present-study}

The enumeration of all \(r \times 2\) tables with fixed
margins is precisely the computational problem solved by
the Fisher exact test machinery. In a companion project,
we developed efficient tree-based and network-based
algorithms for computing Fisher's exact p-value in
general \(r \times 2\) tables. These use memoized pruning
strategies that achieve substantial speedups over
existing implementations. It is a natural conjecture that
this same enumeration machinery could, in principle, be
adapted to the Cochran-Armitage trend statistic. This
would require replacing the probability-based acceptance
criterion with a statistic-based one. Section
\ref{pruning-adaptations} sketches the pruning bounds
such an adaptation would require. We have not, however,
implemented or benchmarked this adaptation in the
present work. It is recorded instead as a proposed
extension (Section \ref{future-research}, item 1), not
as a completed contribution.

What we report here instead is a small, ADEMP-structured
comparison of the trend tests already available for small,
sparse ordered tables. We compare the asymptotic
Cochran-Armitage test and the unordered Fisher exact test
with three two-sided versions of the exact conditional
trend test. These are the equal-tail, mass-based and
mid-p versions. We report Monte Carlo results for a null,
an increasing and a decreasing alternative. For this
small design we also compute size and power exactly, by
summing over the whole sample space. An earlier version
of this report doubled the one-sided \texttt{CATTexact} p-value.
That construction is an upper-tail test at level
\(\alpha/2\) (Section \ref{the-exact-conditional-trend-test}).
We keep it in the tables only to show the size of that
error. The study is narrow. It adds no new design point,
statistic or software to the comparisons of\textsuperscript{\citeproc{ref-corcoran2002exact}{7}},\textsuperscript{\citeproc{ref-lin2006exact}{16}} and\textsuperscript{\citeproc{ref-consiglio2014comparison}{18}}.

\section{Methods}\label{methods}

\subsection{The exact conditional trend test}\label{the-exact-conditional-trend-test}

Consider a \(k \times 2\) contingency table with row
margins \(n_1, \ldots, n_k\) (group sizes) and column
margins \(R_1, R_2\) (total events and nonevents). Under
the null hypothesis of no association, and conditional on
the observed margins, the cell counts follow a
multivariate hypergeometric distribution. Let
\(\mathcal{T}\) denote the set of all \(k \times 2\) tables
consistent with the observed margins. For each table
\(t \in \mathcal{T}\), we define the centered trend
statistic
\[T(t) = \sum_{i=1}^{k} d_i
  \left(x_i(t) - \frac{n_i R_1}{N}\right).\]
Here \(x_i(t)\) is the first-column entry in row \(i\) of
table \(t\). The centering term is the null expectation of
\(\sum d_i x_i(t)\) given the margins, so \(E_0 T = 0\). The
mass-based two-sided exact p-value is
\[p_{\text{mass}} = \sum_{t \in \mathcal{T}}
    \Pr(t) \cdot
    \mathbf{1}\!\left[|T(t)| \geq |T_{\text{obs}}|\right].\]
Here \(\Pr(t)\) is the multivariate hypergeometric
probability of table \(t\). The simulation code stores each
table as its \(2 \times k\) transpose, with groups as
columns. The statistic is the same.

\textbf{Two-sided p-values used in this study.} The function
\texttt{CATTexact::catt\_exact()} returns only the upper-tail
p-value, \(p_{\text{up}} = \Pr(T \geq T_{\text{obs}})\)\textsuperscript{\citeproc{ref-edelmann2025catexact}{21}}. We checked the direction
directly. For counts \((0, 1, 2, 4)\) out of 10 per group,
it returns 0.012. For the reversed counts \((4, 2, 1, 0)\),
it returns 0.996. We obtain the lower tail,
\(p_{\text{lo}} = \Pr(T \leq T_{\text{obs}})\), from the
same function. To do so we reflect the scores to
\(d_i' = d_1 + d_k - d_i\) and reverse the group order.
Given \(R_1\), the statistic under \(d'\) is a constant minus
the statistic under \(d\). So its upper tail is the lower
tail we need. This holds for any increasing scores and
any group sizes. Before each call we shift the scores so
that the smallest is 1. The conditional test is invariant
to such a shift. We found that \texttt{CATTexact} 0.1.1 returns
incorrect p-values for some score vectors that contain
zero. The scores used here, 1 to 4, are not affected.
We compare three two-sided exact
p-values:

\begin{itemize}
\tightlist
\item
  the equal-tail p-value,
  \(p_{\text{eq}} = \min\{2 \min(p_{\text{up}},
  p_{\text{lo}}), 1\}\);
\item
  the mass-based p-value \(p_{\text{mass}}\) defined above;
\item
  the equal-tail mid-p value\textsuperscript{\citeproc{ref-lancaster1961significance}{26}},
  \(p_{\text{mid}} = \min\{2 \min(p_{\text{up}},
  p_{\text{lo}}) - \pi_{\text{obs}}, 1\}\).
\end{itemize}

Here \(\pi_{\text{obs}} = p_{\text{up}} + p_{\text{lo}} - 1\)
is the null probability of the observed value of \(T\). The
mid-p value does not guarantee size at or below \(\alpha\).
We include it as the standard remedy for discreteness\textsuperscript{\citeproc{ref-williams1988tests}{6},\citeproc{ref-hirji2006exact}{25}}. We
compute \(p_{\text{mass}}\) and \(p_{\text{mid}}\) by direct
enumeration of \(\mathcal{T}\) for each value of \(R_1\)
(\texttt{enumerate\_trend\_tables()} in \texttt{sim\_trend\_test.R}). That
enumeration also reproduces both \texttt{CATTexact} tails on
every table of a test design. This check is in the
workspace test suite (\texttt{inst/tinytest/test-exact-trend.R}).

An earlier version of this report doubled the upper tail
alone, \(\min(2 p_{\text{up}}, 1)\). Doubling is a sound
heuristic only for the one-sided p-value in the direction
of the observed statistic. Doubling the upper
tail every time gives a one-sided test at level
\(\alpha/2\). It can never reject for a decreasing trend.
We report that construction as `doubled upper tail' so
that its effect can be seen. It is not a valid two-sided
test.

\subsection{Connection to the Fisher exact test framework (proposed)}\label{connection-to-the-fisher-exact-test-framework-proposed}

This subsection and Section \ref{pruning-adaptations}
describe a proposed adaptation of the companion Fisher
exact test enumeration machinery to the trend statistic.
We note that neither the tree-based traversal nor the
pruning bounds below have been implemented, run, or
benchmarked in this repository. The simulation study in
Section \ref{simulation-design} uses the existing
\texttt{CATTexact} implementation instead, together with
brute-force enumeration of the whole sample space. The
tree-based adaptation is future work (see Section
\ref{future-research}, item 1). The bounds are recorded
here as a mathematically well-defined starting point for
future implementation work. They are not a completed or
evaluated contribution of this report.

In the standard Fisher exact test for \(r \times 2\)
tables, the p-value is
\[p_{\text{Fisher}} = \sum_{t \in \mathcal{T}}
    \Pr(t) \cdot
    \mathbf{1}\!\left[\Pr(t) \leq \Pr(t_{\text{obs}})
    \right].\]
The only difference between the two tests is the
ordering criterion. Fisher's test orders tables by their
probability. The exact trend test, on the other hand,
orders them by the absolute value of the trend statistic.
The enumeration of \(\mathcal{T}\) and the computation of
\(\Pr(t)\) are identical between the two tests. This means
that two pieces of our \(r \times 2\) Fisher exact test
package can in principle be adapted to the trend test.
These are the tree-based traversal with
find\_max/find\_min pruning and the network-based
state-space enumeration. The adaptation
would replace the probability-based acceptance criterion
with a statistic-based one.

\subsection{Pruning adaptations}\label{pruning-adaptations}

These bounds are derived analytically as a proposed
extension (see the note at the start of Section
\ref{connection-to-the-fisher-exact-test-framework-proposed}).
They have not been coded or tested against a reference
implementation. We make no runtime or correctness claim
for them here.

The key algorithmic question is whether the pruning
strategies developed for the probability ordering
transfer to the statistic ordering. In the
probability-ordered Fisher test, the find\_max and
find\_min bounds allow entire subtrees to be skipped.
This occurs when all tables in the subtree have
probability above or below the threshold. For the trend
test, analogous bounds on the trend statistic are
needed.

Consider a partial table with values \(x_1, \ldots, x_j\)
assigned to the first \(j\) rows, and remaining column
margin \(c_1' = R_1 - \sum_{i=1}^{j} x_i\). Write
\(\mu = R_1 \sum_i d_i n_i / N\) for the centering constant.
The minimum and maximum achievable values of the centered
\(T\) over all completions are
\begin{align*}
T_{\min} &= \sum_{i=1}^{j} d_i x_i +
  \min_{\{x_{j+1},\ldots,x_k\}}
  \sum_{i=j+1}^{k} d_i x_i - \mu, \\
T_{\max} &= \sum_{i=1}^{j} d_i x_i +
  \max_{\{x_{j+1},\ldots,x_k\}}
  \sum_{i=j+1}^{k} d_i x_i - \mu.
\end{align*}
The optimization is over integers with
\(0 \leq x_i \leq n_i\) and \(\sum_{i>j} x_i = c_1'\). If the
scores are sorted, both bounds follow from a greedy
allocation in \(O(k-j)\) time. The remaining margin fills
the rows with the largest scores first for \(T_{\max}\), up
to each \(n_i\). It fills the smallest scores first for
\(T_{\min}\). Two cases then allow a whole subtree to be
handled at once. First, if
\(T_{\min} > -|T_{\text{obs}}|\) and
\(T_{\max} < |T_{\text{obs}}|\), no completion reaches the
rejection region. The subtree is pruned. Second, if
\(T_{\min} \geq |T_{\text{obs}}|\) or
\(T_{\max} \leq -|T_{\text{obs}}|\), every completion is in
the rejection region. The subtree's total probability is
then added in closed form. This is the analogue of
find\_max/find\_min acceptance in the Fisher tree. By the
Vandermonde identity, the subtree's total probability is
\(\prod_{i \leq j} \binom{n_i}{x_i}
\binom{\sum_{i>j} n_i}{c_1'} / \binom{N}{R_1}\).

\subsection{Simulation design}\label{simulation-design}

\subsubsection{ADEMP structure}\label{ademp-structure}

This simulation study is reported following the ADEMP framework of
Morris, White, and Crowther\textsuperscript{\citeproc{ref-morris2019using}{27}}.

\textbf{Aims.} Compare type I error and power of five trend-test
procedures under small-sample binomial outcomes.

\textbf{Data-generating mechanisms.} Three scenarios, all with
\(k = 4\) groups of size \(n_i = 10\) and scores
\(d = (1, 2, 3, 4)\):

\begin{itemize}
\tightlist
\item
  Null: \(p_i = 0.2\) for all groups.
\item
  Increasing alternative: \(p = (0.05, 0.10, 0.20, 0.35)\),
  representing a dose-response relationship.
\item
  Decreasing alternative: \(p = (0.35, 0.20, 0.10, 0.05)\),
  the same alternative in reverse order.
\end{itemize}

For exact size we also use a grid of common null
probabilities, \(p \in \{0.02, 0.03, \ldots, 0.50\}\). Exact
computations only, with no Monte Carlo counterpart, cover
three more cases. Two are further alternative shapes with
\(n_i = 10\): a threshold, \(p = (0.10, 0.10, 0.10, 0.40)\),
and a plateau, \(p = (0.05, 0.25, 0.25, 0.25)\). The third
is an unequal design, \(n = (5, 10, 10, 15)\), under the
null and both linear alternatives.

\textbf{Estimands.} The probability of rejecting
\(H_0: \text{no trend}\) at \(\alpha = 0.05\). Under the null
this is the size. Under an alternative it is the power.

\textbf{Methods.} (i) Asymptotic Cochran-Armitage trend test
(two-sided). (ii) Fisher's exact test (unordered).
(iii) Exact conditional Cochran-Armitage test, equal-tail,
with both tails from \texttt{CATTexact::catt\_exact()}. (iv) The
same test, mass-based. (v) The same test, equal-tail
mid-p.~(vi) The doubled upper tail, kept for comparison
only (Section \ref{the-exact-conditional-trend-test}).

\textbf{Performance measures.} Rejection rate at
\(\alpha = 0.05\), mean p-value, and median p-value. Monte
Carlo SEs are given for the rejection rate and the mean
p-value, following\textsuperscript{\citeproc{ref-morris2019using}{27}}, Table 6. For this
design the sample space has only \(11^4 = 14{,}641\)
tables. So we also compute each method's rejection
probability exactly, by summing the product-binomial
probability of every table on which it rejects
(\texttt{exact\_rejection()} in \texttt{sim\_trend\_test.R}). These exact
values carry no Monte Carlo error.

\textbf{Simulation size.} \(B = 2{,}000\) replications per
scenario. \(B\) was chosen as a round number. It was not
derived from a target MCSE. Under the null, with a
rejection rate near 0.05, the MCSE is about
\(\sqrt{0.05 \times 0.95 / 2000} \approx 0.005\). Under the
alternatives the realized powers lie between about 0.25
and 0.45. There the MCSE is close to 0.01. That is its
maximum, reached at a rate of 0.5. A worst-case target of 0.01 would have needed
\(B \geq 2{,}500\). The exact computations make this
shortfall unimportant for the conclusions. The Monte
Carlo results serve as a check on them.

\subsubsection{Reproducibility of the simulation}\label{reproducibility-of-the-simulation}

The RNG is set once, by \texttt{RNGkind("L\textquotesingle{}Ecuyer-CMRG")} and
\texttt{set.seed(20260417)} above. The three scenarios then run
in sequence from the same stream. The function
\texttt{sim\_trend\_test()} does not reseed. It stores
\texttt{.Random.seed} for every replication. An audit of these
points against\textsuperscript{\citeproc{ref-morris2019using}{27}} is in
\texttt{docs/morris-audit-2026-04-17.md} in the repository.

\section{Discussion}\label{discussion}

The simulation results characterize the observed operating
characteristics of the exact conditional Cochran-Armitage
trend test. We compare it with the asymptotic version and
the unordered Fisher exact test, in one small, sparse
data-generating regime. Several findings merit discussion.

First, the construction of the two-sided exact p-value
matters a great deal. \texttt{CATTexact} returns an upper-tail
p-value only. Doubling it, as an earlier version of this
report did, gives an upper-tail test at level \(\alpha/2\).
Its exact size at \(p = 0.2\) is 0.015.
Its power against a decreasing trend is
0.000. Using both tails raises
the exact size at \(p = 0.2\) to 0.030.
So about half of the low size that the earlier version
reported was due to this error. It was not a property of
the exact conditional test. Users of \texttt{CATTexact} should
compute
both tails, as in Section
\ref{the-exact-conditional-trend-test}. The same problem
can arise with any software that returns a one-directional
p-value.

Second, after the correction the equal-tail exact test is
still conservative. Its exact size at \(p = 0.2\) is
0.030, against 0.040 for
Fisher's test. Both tests condition on the same margins
and use the same reference set. They differ only in the
ordering that defines the rejection region. So no a priori
argument says which should have size closer to nominal.
The gap is a matter of granularity. Under the trend
ordering, the attainable p-values near \(\alpha\) are
sparser for these margins (Section
\ref{type-i-error-control-scenario-1}). The mid-p
version removes most of this conservatism. Its exact size
stays below \(\alpha\) over the whole grid of null
probabilities in Figure \ref{fig:size-curve}. That is a
property of this design, not a guarantee. Mid-p tests can
exceed \(\alpha\) in other settings\textsuperscript{\citeproc{ref-hirji2006exact}{25}}.

Third, in this design the asymptotic test performed well.
It had the highest power at the nominal level. Its size
was close to nominal and exceeded \(\alpha\) only slightly,
near \(p = 0.5\).\textsuperscript{\citeproc{ref-corcoran2002exact}{7}} studied the same
design, four groups of ten. They found that the asymptotic
test exceeds \(\alpha\) for most baseline probabilities.
Their tests were one-sided, however. We computed the
exact size of the one-sided asymptotic test in this
design. It exceeds \(\alpha\) at 21 of the
49 grid points, with a maximum size of
0.052. So we reproduce their direction but
not their extent. We have not resolved this difference.
It may reflect details of their computation that we did
not replicate. The two-sided test exceeds \(\alpha\) less
often. This suggests that errors in the two tails of the
normal approximation partly cancel. We have not shown
this directly.
We studied one design only. So we do not claim that the
asymptotic test is adequate in general. The exact trend test gained power
over the unordered Fisher test. This is consistent with
the motivation for trend tests dating to\textsuperscript{\citeproc{ref-cochran1954methods}{1}} and\textsuperscript{\citeproc{ref-armitage1955tests}{2}}. The gain is,
however, confounded by unequal realized sizes (Section
\ref{power-comparison-scenario-2}).

Fourth, this study does not implement or benchmark the
tree-based pruning adaptation sketched in Section
\ref{pruning-adaptations}. The exact p-values used here
come from \texttt{CATTexact} and from brute-force enumeration of
an \(11^4\) sample space. Brute force is feasible only for
very small designs. No runtime comparison against the
network algorithm has been performed. This remains future
work (Section \ref{future-research}, item 1).

The conditional approach has known limitations beyond
the construction of the two-sided p-value. By conditioning
on both sets of margins, it can be conservative relative
to unconditional exact tests\textsuperscript{\citeproc{ref-shan2012efficient}{17},\citeproc{ref-consiglio2014comparison}{18}}. This
conservatism arises because the conditional reference
set is a subset of the unconditional reference set. As a
result, the p-value function can show discrete jumps.
Whether this conservatism is acceptable depends on the
regulatory context. It also depends on the desired
balance between type I error control and power\textsuperscript{\citeproc{ref-agresti2001exact}{14}}.

\subsection{Limitations}\label{limitations}

This study has several limitations. (1) The comparison
covers a single design: \(k = 4\) groups of size 10 with
equally spaced scores. It has one null configuration
(with an exact size curve over the null probability) and
one alternative shape in two directions. The relative
ranking of the tests may not generalize to other group
counts, unequal group sizes, unequal score spacing, or
other alternative shapes. In particular, the mass-based
and equal-tail exact tests coincide here only by the
symmetry of the design. (2) The exact computations rely
on brute-force enumeration. That is feasible only for
very small designs like this one. (3) Two competitors are
not included in the empirical comparison. These are the
unconditional exact trend test\textsuperscript{\citeproc{ref-tang2000exact}{15},\citeproc{ref-shan2012efficient}{17}} and the
Bartholomew-statistic tests of\textsuperscript{\citeproc{ref-consiglio2014comparison}{18}}. Both are cited as competitors
with claimed higher power than the conditional exact
test. (4) The tree-based pruning algorithm that motivated
this study's original framing is not implemented or
evaluated here (Section \ref{pruning-adaptations}).
(5) \(B = 2{,}000\) replications per scenario was not
derived a priori from a target Monte Carlo SE, as\textsuperscript{\citeproc{ref-morris2019using}{27}} recommend. Under the alternatives the
realized MCSE is close to 0.01. A worst-case target of
0.01 would have required \(B \geq 2{,}500\). The exact
computations in Table \ref{tab:table-exact} do not
depend on \(B\).

use any external or restricted data. All results are
generated from the data-generating mechanisms in Section
\ref{simulation-design}, either by Monte Carlo
simulation or by exact enumeration. The RNG seed is fixed
once (\texttt{set.seed(20260417)} after
\texttt{RNGkind("L\textquotesingle{}Ecuyer-CMRG")}). The three scenarios then run
in sequence.

\section{Future research}\label{future-research}

Several extensions of the current work merit
consideration.

\begin{enumerate}
\def\labelenumi{\arabic{enumi}.}
\item
  \textbf{Implementation in C/C++.} The present study
  uses \texttt{CATTexact} and brute-force enumeration for the
  exact conditional test. A direct implementation would
  use the tree-based and network-based algorithms from
  the companion \(r \times 2\) Fisher exact test project.
  These would be adapted per Sections
  \ref{connection-to-the-fisher-exact-test-framework-proposed}
  and \ref{pruning-adaptations}. Such an implementation
  would allow performance comparisons. It would also
  give mass-based two-sided p-values for designs too
  large for brute force. It should be validated against
  the enumeration used here, and against \texttt{coin}, on a
  grid of tables.
\item
  \textbf{Broader designs.} Table \ref{tab:exact-extra} adds
  only two alternative shapes and one unequal design.
  Exact size and power should also be computed for
  \(k \in \{3, 5, 6\}\), other unequal \(n_i\), and unequally
  spaced scores, with alternatives in both directions.
  The mass-based and equal-tail tests differ in such
  designs. Their comparison then becomes informative.
\item
  \textbf{Unconditional exact trend tests.} Following\textsuperscript{\citeproc{ref-tang2000exact}{15}} and\textsuperscript{\citeproc{ref-shan2012efficient}{17}}, the
  unconditional exact approach
  merits implementation using the same enumeration
  infrastructure. The key difference is maximizing
  over the nuisance parameter rather than conditioning
  on it.
\item
  \textbf{Alternative score functions.} The choice of scores
  \(d_i\) affects power. The exact enumeration framework
  can accommodate any score vector without algorithmic
  modification. Robust tests that combine several score
  vectors (MAX-type tests) are a natural comparator.
\item
  \textbf{Stratified exact trend tests.} The algorithm of\textsuperscript{\citeproc{ref-mehta1992exact}{12}} handles stratification. Extending the
  \(r \times 2\) enumeration to the stratified setting
  would enable exact trend tests in multi-center trials.
\item
  \textbf{Order-restricted inference.}\textsuperscript{\citeproc{ref-agresti1998order}{28}}
  developed methods for monotone trend alternatives
  using order-restricted maximum likelihood estimation.
  Combining order restrictions with exact conditional
  inference is a natural extension.
\item
  \textbf{Software package.} A dedicated R package built
  on shared C/C++ enumeration code could unify the
  Fisher exact test and exact trend test for
  \(r \times 2\) tables. It would provide a practical tool
  for applied statisticians working with small-sample
  ordered categorical data.
\end{enumerate}
