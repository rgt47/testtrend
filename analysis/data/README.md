# Data Directory

This project uses no external or restricted data. All results in
`analysis/report/report.Rmd` are generated by Monte Carlo
simulation from the data-generating mechanisms described in the
manuscript's "Simulation design" section.

## Directory structure

```
data/
├── raw_data/            # Empty; no raw data used by this project
├── derived_data/         # Simulation output, regenerated by report.Rmd
└── README.md             # This file
```

## Derived data (`derived_data/`)

| File | Source | Description |
|------|--------|-------------|
| `sim_null.rds` | `analysis/report/report.Rmd`, chunk `sim-null` | Per-replication simulation output under the null scenario ($B = 2{,}000$) |
| `sim_alt.rds` | `analysis/report/report.Rmd`, chunk `sim-alt` | Per-replication simulation output under the alternative (dose-response) scenario ($B = 2{,}000$) |

Both files are regenerated whenever `report.Rmd` is rendered (see
`analysis/scripts/sim_trend_test.R`). They are saved here so the
manuscript's inline `r` expressions and tables can read observed
values rather than hardcoded numbers, and so a reader can inspect
the raw per-replication output independent of the rendered report.

## Reproducibility

To regenerate the simulation output directly (without rendering the
full report):

```r
source("analysis/scripts/sim_trend_test.R")
RNGkind("L'Ecuyer-CMRG")
set.seed(20260417)
sim_null <- sim_trend_test(
  n_per_group = rep(10, 4), true_probs = rep(0.2, 4),
  scores = 1:4, n_rep = 2000
)
sim_alt <- sim_trend_test(
  n_per_group = rep(10, 4),
  true_probs = c(0.05, 0.10, 0.20, 0.35),
  scores = 1:4, n_rep = 2000
)
```
